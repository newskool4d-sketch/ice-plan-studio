# 한글 설치 환경 수동 검증 체크리스트

목적: 자동 XML 검증으로 확인할 수 없는 한글 화면·개체 속성을 최종 확인한다.

## 준비물

- `release\ICE Plan Studio Setup 0.1.0.exe` 설치본 또는 `release\win-unpacked\ICE Plan Studio.exe`
- `test-data\sample-plan-semantic.hwpx`: 표 기본 동작 확인
- `test-data\long-table.hwpx`: 여러 페이지 표 확인
- `test-data\paragraph-style.hwpx`: 문단·줄간격 확인
- 원본 `test-data\long-table.md`: 원본 보존 확인용

## 실행 절차

1. 설치본을 실행한다.
2. `sample-plan-semantic.hwpx`를 한글에서 연다.
3. 표를 선택하고 개체 속성에서 `글자처럼 취급`이 해제되어 있는지 확인한다.
4. 표 너비가 A4 본문 영역 안에 들어오는지 확인한다.
5. `long-table.hwpx`를 열고 표가 다음 페이지로 넘어갈 때 머리글이 반복되는지 확인한다.
6. 긴 셀 텍스트가 셀 밖으로 잘리지 않고 줄바꿈되는지 확인한다.
7. `paragraph-style.hwpx`에서 제목·본문의 글꼴 크기, 줄간격, 내어쓰기 상태를 확인한다.
8. `.iceprofile`과 `.iceplan`을 저장한 뒤 다시 불러와 CI·슬로건과 문서 내용이 복원되는지 확인한다.
9. 저장하지 않고 닫은 뒤 원본 MD/TXT 파일의 수정 시간이 변하지 않았는지 확인한다.

## 판정 기준 및 기록

| ID | 확인 항목 | 기대 결과 | 결과 | 증거/메모 |
|---|---|---|---|---|

| H-02 | 표 본문 너비 | A4 본문 영역 안쪽 | 통과(2026-07-19) | 한글 PDF 변환 렌더링 확인 |
| H-03 | 표 페이지 넘김 | 다음 페이지에서 머리글 반복 | 통과(2026-07-19) | `multipage-table.hwpx` 2페이지 머리글 반복 확인 |
| H-04 | 긴 셀 줄바꿈 | 셀 밖 잘림 없음 | 통과(2026-07-19) | 잘림 없음. 셀 우측 여백 밀착은 관찰사항 |
| H-05 | 문단 스타일 | 제목·본문 토큰과 일치 | 통과(2026-07-19) | `paragraph-style.hwpx` PDF 렌더링 확인 |

| H-07 | 원본 보존 | MD/TXT 수정 없음 | 통과(2026-07-19) | 검증 전후 mtime 불변 |

2026-07-19: 한글 2020 COM 자동화(`HWPFrame.HwpObject`)로 H-01~H-05·H-07 검증 완료.
과정에서 `rowCnt`/`colCnt` 누락(열기 실패), 머리글 셀 `header="1"` 누락(반복 미작동),
본문 자동번호 오작동·`**굵게**` 미처리 결함을 발견·수정했다. 실전 샘플(재구조화안, 96블록·
8표)로 재검증 완료.

H-06은 CDP(Chrome DevTools Protocol)로 패키징된 렌더러를 직접 조작해 검증했다. 그 과정에서
**렌더러가 완전히 빈 화면으로 뜨는 치명 결함 2건**(Vite 자산 경로가 `file://`에서 깨짐,
`App.jsx` 핸들러 함수가 JSX map 콜백 안에 잘못 위치해 렌더링 크래시)을 발견·수정했다 —
기존 "실행 파일 시작 확인" 스모크 테스트는 프로세스 생존만 확인해 이 결함들을 놓쳤다.

또한 문서 미리보기 본문·검토 패널이 `loadedModel`에 연결되지 않은 정적 데모 화면임을
확인했다(기능 격차, 결함 아님 — 규칙 계산 자체는 정상 동작).

상세 내역·재발견 결함·기능 격차 전체는 `docs\MVP_CHECKPOINT.md` 참조.
남은 항목: 설치본(.exe) 재빌드 후 재검증, HWPX 내보내기 저장 다이얼로그 실물 클릭 확인.
