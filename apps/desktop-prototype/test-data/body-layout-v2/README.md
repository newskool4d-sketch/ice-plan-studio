# 기본계획 본문 조판 v2 계약 fixture

단계 1에서 구현 전에 고정하는 합성 fixture다. 실제 계획서 본문이나 개인정보를 복제하지 않는다.

## 목적

다음 동작을 문서 계약으로 고정한다.

1. 목차가 원문에 있으면 원문을 보존한다.
2. 목차가 없으면 사용자에게 묻고, 선택에 따라 빈 틀 또는 명시적 제외를 기록한다.
3. 요약이 없으면 자동 작성하지 않고 빈 틀 또는 명시적 제외를 기록한다.
4. 본문 시작 쪽과 본문 후속 쪽을 구분한다.
5. 불릿 권고를 무시한 담당자의 선택을 보존한다.
6. worldschool-2026의 본문 기준을 14pt로 고정하고 경계 조판을 별도 교정한다.

## 구성

| 파일 | 역할 |
|---|---|
| contract-fixtures.json | 7개 합성 fixture, 기대 페이지 순서, 결정 상태, 금지 조건 |
| verify-body-layout-v2-baseline.mjs | 구현 전 현재 엔진의 알려진 격차를 확인하는 baseline audit |

## 실행

    cd apps/desktop-prototype
    npm run verify:body-layout-v2-baseline

이 명령은 제품 기능의 통과 게이트가 아니다. 구현 전에는 expected-gap을 확인해 passed: true를 반환한다. 구현이 진행되면 같은 fixture를 실제 기능 게이트로 승격해야 한다.

## 판정 규칙

- source 모드는 원문 내용만 사용한다.
- template 모드는 제목·장식·입력 영역만 제공하며 합성 본문을 넣지 않는다.
- omitted 모드는 사용자 결정과 경고만 저장한다.
- body-opening은 한 번만 존재하고 body-continuation에는 전체 제목 띠를 반복하지 않는다.
- 검은색 줄간격 마킹과 목차 항목 입력, 요약 내용 입력 등의 합성 문구는 최종 산출물에 없어야 한다.
- 14pt 적응 조판은 별도 재교정 전까지 구현 완료로 간주하지 않는다.
