## 1. 과제 A — 표지 개선 4항목

현행 정본: `hwpx-toolkit/templates/boncheong/cover-anchor.xml` + 같은 템플릿 `BinData/image1.png(구 슬로건)·image2.png(CI 339px)`. 미리보기 쌍둥이: `public/branding/*.png` + `previewProjection.js`/표지 렌더 컴포넌트.

### A-1. 슬로건 교체

- 우측 상단 배치는 현행 paraPr 22(RIGHT)로 이미 충족 — 위치 변경 불필요
- 미리보기 `public/branding/incheon-slogan.png`·`assets/branding/image01.png` 동시 교체
- `agencyProfiles.js`의 슬로건 문구 문자열("함께 가는 인천교육…")도 신규 문구로 갱신

### A-2. CI 위치 정렬 + 고해상 교체
- 구조상 현행도 가운데(paraPr 25 CENTER, treatAsChar=1) — **실물 COM 변환 후 치우침 여부 육안 확인**이 선행 (이미지 내부 여백·intent 원인 가능)
- BinData/image2.png 339px → 신규 562px 교체, 크기를 실물 실측 12421×12120HU(43.8mm)로 상향 (현행 10318HU=36.4mm)

### A-3. 하단 교육청 명칭: 텍스트 → 그림
- 현행: `인천광역시교육청 ○○과`(charPr 15) 텍스트 1줄 + 영문명 텍스트 슬롯
- 개선: **[명칭 이미지(가운데, 22991×3840HU)] + [부서명 텍스트 줄]** 2단 구성 — 실물 ⑤⑥ 구조와 동일
- 신규 BinData `image3` 등록 + `content.hpf` manifest `opf:item` 추가 필수 (누락 시 한글 열기 거부)
- 영문명 텍스트 슬롯: 이미지에 영문 병기가 포함되므로 **본청 프로필에서는 비움** — 단, 직속기관 프로필(direct-g)은 기관명이 다르므로 명칭 이미지 미적용·현행 텍스트 유지로 **프로필 분기** (`layout_engine.py` CoverProfile에 플래그 추가)
- `boncheong_cover_paragraphs()`(model_to_hwpx.py)의 치환 로직·앵커 슬롯 재사용 로직 함께 수정

### A-4. 제목틀 내부 불필요한 빈 줄 제거 — ✅ 원인 확정 (2026-08-12 사용자 답변 반영)
**증상**: 실조판 SVG(kordoc renderHwpxToSvg — 생성된 HWPX를 충실 반영)에서 제목이 제목틀 안에서 한 줄 내려와 있음. 원래 양식에 없는 줄이 구현 과정에서 추가된 결함.

**원인 (코드·실물 대조 확정)**:
- 현행 `cover-anchor.xml` 제목 셀(r1c0)은 **문단 2개**: ①`기본 방향 문구를 입력하세요`(charPr 18) ②제목(charPr 512)
- 실물 양식 샘플의 제목 셀은 **제목 문단 1개뿐** — 기본방향 문구 문단 자체가 없음
- `boncheong_cover_paragraphs()`(model_to_hwpx.py:299)가 direction 미입력 시 placeholder를 **빈 문자열로 치환** → 빈 문단이 남아 제목을 한 줄 밀어냄

**개선**: direction이 비어 있으면 해당 **문단을 통째로 제거**(빈 치환 금지), 값이 있으면 현행처럼 문단 유지. React 빠른 미리보기(PlanPreview.jsx:63)는 이미 조건부 숨김이라 수정 불필요 — HWPX 생성 경로만 고치면 실조판 SVG도 함께 해결.
