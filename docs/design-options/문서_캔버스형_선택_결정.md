# ICE Plan Studio 디자인 방향 선택 결정

- 결정일: 2026-07-19
- 결정 상태: 확정
- 선택안: **03 문서 캔버스형 (IBM + Miro + Technical Blueprint)**

## 선택 이유

교육청 계획안 자동서식 도구의 핵심은 마케팅 화면이 아니라 A4 문서의 구조·조판·오류 위치·수정 결과를 정확히 확인하는 것이다. 문서 캔버스형은 이 목적에 가장 직접적으로 맞는다.

- A4 페이지가 화면의 중심이 된다.
- 페이지 썸네일로 문서 전체 흐름을 확인할 수 있다.
- 표 너비·여백·페이지 경계 등 조판 근거를 실제 위치에 연결할 수 있다.
- 우측 인스펙터에서 현재값·권장값·적용 결과를 비교할 수 있다.
- 긴 문서와 다수의 표를 검토하는 작업 흐름에 적합하다.

## 구현 기준선

1. 03번 시안의 `페이지 썸네일 → A4 캔버스 → 규칙 인스펙터` 구조를 기본 레이아웃으로 삼는다.
2. 01번 시안의 엄격한 그리드와 정보 정렬 원칙을 병합한다.
3. 02번 시안의 단계 상태 표시를 하단 또는 상단 작업 상태에 제한적으로 병합한다.
4. 치수선·번호·경고 표시는 실제 문서 객체와 연결된 경우에만 노출한다.
5. 공식 CI와 슬로건은 앱 장식이 아니라 승인된 브랜드 자산 슬롯으로 배치한다.
6. 시안 이미지의 문구·색상·아이콘은 최종 자산으로 간주하지 않고, 실제 토큰·문서·브랜드 원본으로 교체한다.

## 첫 구현 대상

첫 화면 구현은 전체 앱이 아니라 다음 단일 흐름으로 제한한다.

`규칙 검토 화면 열기 → 표 너비 초과 선택 → 현재값·권장값 확인 → 적용 또는 되돌리기`
