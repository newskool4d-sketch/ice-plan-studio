## 3. 쪽 역할 기준선

물리 쪽은 PDF 파일 내 순서를, 인쇄 쪽 번호는 본문에 표시되는 번호를 뜻한다.

| 물리 쪽 | 쪽 역할 | 인쇄 쪽 번호 | 확정 조판 |
|---:|---|---:|---|
| 1 | `cover` | 없음 | 독립 표지 |
| 2 | `toc` | 없음 | 목차 제목 틀, 외곽선, 항목, 점선, 본문 쪽 번호, 부록 |
| 3 | `summary` | 없음 | 문서 요약 제목, 정의, 비전, 목표, 추진과제, 단계, 협력체계 |
| 4 | `body-opening` | `- 1 -` | 문서 상단 제목 틀과 첫 장 내용을 함께 배치 |
| 5 이후 | `body-continuation` | `2`부터 | 전체 문서 제목 틀을 반복하지 않고 장·절·본문을 연속 배치 |

확정 순서는 다음과 같다.

```text
cover → toc → summary → body-opening → body-continuation*
```

학교 배포용 기본계획의 앞부분은 본문 쪽 번호 계산에서 제외하고, 실제 내용이 시작되는 `body-opening`부터 `1`을 부여한다.

## 4. `worldschool-2026` 실측 조판 토큰

### 4.1 목차

| 요소 | 관찰 글꼴 | 크기 | 적용 규칙 |
|---|---|---:|---|
| `목 차` | H2hdrM | 20pt | 독립 제목 상자 |
| 주요 장 항목 | H2hdrM | 17pt | 로마숫자, 제목, 점선, 쪽 번호 |
| 부록 항목 | PDF 내 명조 계열 | 15pt | 대괄호 부록 번호와 제목 |
| 점선·쪽 번호 영역 | H2hdrM | 12pt | 제목 길이에 따라 연결선 길이 조정 |

목차 내용이 원문에 있으면 보존한다. 원문에 목차가 없고 사용자가 틀 추가를 선택하면 제목·외곽선·항목 배치 영역만 제공하며 `목차 항목 입력` 같은 문장은 넣지 않는다.

### 4.2 요약

| 요소 | 관찰 글꼴 | 크기 | 적용 규칙 |
|---|---|---:|---|
| 요약 주 제목 | HYwulM | 22pt | 상단 색상선과 제목 띠 |
| 정의·비전·목표 | 맑은 고딕/H2hdrM 계열 | 11~14pt | 역할별 상자 구조 |
| 추진과제 | 맑은 고딕/H2hdrM 계열 | 11~14pt | 3열 구조는 이 문서 프로필의 원문 구조 |
| 추진단계·협력체계 | 맑은 고딕 계열 | 11~14pt | 하단 단계·띠 구조 |

요약이 원문에 있으면 원문 구조를 보존한다. 요약이 없으면 빈 요약 틀 제공 여부를 사용자가 선택하며, 본문을 읽어 요약문을 자동 생성하지 않는다.

### 4.3 본문 시작 쪽

| 요소 | 관찰 글꼴 | 크기 | 적용 규칙 |
|---|---|---:|---|
| 슬로건 | HYwulM | 16pt | 문서명 위 |
| 문서명 | HYwulM | 24pt | 회색 제목 띠 중앙 |
| 담당 부서 | HYwulM | 15pt | 제목 띠 아래 오른쪽 |
| 장 제목 | H2hdrM | 18pt | 파란 로마숫자 상자, 제목, 하단선 |
| 본문 | HCRBatang | 14pt | 원문 줄바꿈·목록 위계를 우선 보존 |
| 인용·근거 상자 | HanSantteutDotumRegular | 11pt | 연한 색상 배경 |
| 쪽 번호 | HCRDotum | 10pt | 본문 시작 쪽을 `- 1 -`로 표시 |

본문 시작 쪽에만 다음 묶음을 배치한다.

```text
다색 상단선
→ 회색 제목 띠
→ 슬로건
→ 문서명
→ 담당 부서
→ 첫 장 제목과 본문
```

### 4.4 본문 후속 쪽

| 요소 | 관찰 글꼴 | 크기 | 적용 규칙 |
|---|---|---:|---|
| 장 제목 | H2hdrM | 18pt | 파란 로마숫자 상자, 제목, 하단선 |
| 본문 | HCRBatang | 14pt | 목록·하위 항목 포함 |
| 쪽 번호 | HCRDotum | 10pt | 연속 번호 |
| 문서 전체 제목 띠 | 없음 | - | 후속 쪽에 반복하지 않음 |

물리 5쪽은 `추진 목적`, `추진 경과`만 배치하고 물리 4쪽의 문서명 제목 띠를 반복하지 않는다. 따라서 구현 모델은 `body` 하나가 아니라 `body-opening`과 `body-continuation`을 구분해야 한다.

### 4.5 구조 제목 변형

본문 제목이 다음 표기 중 하나로 시작하면 로마숫자 장 제목과 같은 1행 2열 표 구조를 사용한다.

| 시작 표기 | 제목 크기 | 구분 색상 | 적용 |
|---|---:|---|---|
| `Ⅰ.` 등 로마숫자 | 18pt | 청색 | 장 제목 기준형 |
| `[과제1]`, `[과제 1]` | 14pt | 녹색 | 과제 제목 |
| `[과제 1-1]` | 12pt | 청회색 | 세부과제 제목 |

왼쪽 셀에는 시작 표기를, 오른쪽 셀에는 제목을 배치한다. 과제와 세부과제는 로마숫자 장 제목보다 작게 표시하며, 빠른 미리보기와 HWPX에서 같은 계층·색상·크기를 유지한다.

## 6. 목차·요약 결정 계약

### 6.1 목차

학교 배포용 기본계획은 목차 결정이 필수다.

| 입력 상태 | 시스템 동작 | 최종 내용 생성 |
|---|---|---|
| 원문 목차 있음 | 전용 목차 쪽으로 분리·보존 | 원문만 사용 |
| 원문 목차 없음, 틀 추가 선택 | 빈 목차 틀 생성 | 생성하지 않음 |
| 원문 목차 없음, 제외 선택 | 경고 확인과 사용자 결정을 기록 | 생성하지 않음 |

목차가 없는 경우 질문은 다음 문구를 기준으로 한다.

> 목차 쪽이 없습니다. 목차 틀을 추가할까요?

### 6.2 요약

| 입력 상태 | 시스템 동작 | 최종 내용 생성 |
|---|---|---|
| 원문 요약 있음 | 전용 요약 쪽으로 분리·보존 | 원문만 사용 |
| 원문 요약 없음, 틀 추가 선택 | 빈 요약 구조 제공 | 생성하지 않음 |
| 원문 요약 없음, 제외 선택 | 요약 쪽을 추가하지 않음 | 생성하지 않음 |

빈 틀은 입력 영역의 구조만 제공한다. `요약 내용 입력` 같은 안내 문장은 최종 HWPX/PDF에 포함하지 않는다.

## 7. 불릿·항목기호 기준

1. 원문 기호와 들여쓰기 수준을 우선 보존한다.
2. 공문서 기재 관행은 권고로 제시하고 자동 강제하지 않는다.
3. 담당자는 권고 적용, 권고 무시, 직접 선택 중 하나를 결정할 수 있다.
4. 원문 기호, 시스템 권고, 사용자 결정을 각각 저장한다.
5. 사용자 결정은 저장·다시 열기·HWPX 왕복 후에도 유지한다.
6. 검은색 줄간격 마킹은 불릿·구분선·문단 배경으로 해석하지 않는다.

## 8. 기존 분석과의 충돌 정리

기존 문서는 당시 레퍼런스 집합에 대한 역사적 기록으로 보존한다. 이번 프로필에서는 아래 보완 기준이 우선한다.

| 기존 위치 | 기존 해석 | 이번 보완 기준 |
|---|---|---|
| `BASELINE_ANALYSIS.md:28` | A 유형 `표지 → 목차 → 본문` | 이번 기준 PDF는 `표지 → 목차 → 요약 → 본문` |
| `BASELINE_ANALYSIS.md:124` | A 본문 12pt 함초롬바탕 | `worldschool-2026` 본문은 HCRBatang 14pt |
| `REBASELINE_PLAN.md:75` | 문서 제목 밴드 반복 | 이 프로필은 `body-opening`에만 제목 띠 배치 |
| `REBASELINE_PLAN.md:201-202` | 반복 헤더를 제목 밴드·쪽 번호로 설명 | 이 프로필의 후속 쪽에는 제목 밴드가 없고 쪽 번호만 연속 |

이 보완은 모든 기존 A 유형을 일괄 재분류하는 결정이 아니다. 레퍼런스마다 다른 구성을 `layoutProfile`로 분리하기 위한 근거다.
